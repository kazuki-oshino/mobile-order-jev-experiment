# デジタル接客版の生成画像

内蔵 `image_gen` で新規生成し、ワークスペースにコピーしました。CLIは使っていません。
画像ファイルはアトラス形式で、CSSの背景位置によって20商品・5表情を個別に表示します。

- ドーナツ20種: `public/images/donuts-20.png`（5列×4行）
- 同一の架空店員の5表情: `public/images/jev-faces.png`（横5列）
- 前版の `public/images/donuts.png` は未使用の履歴素材として保持しています。
